ID & Class

Os dois atributos que dão nome e agrupam elementos no HTML — a base de todo seletor CSS e de toda manipulação via JavaScript.

Atributo id

Identifica um único elemento na página. Um mesmo id não deve se repetir em outro elemento do mesmo documento.

<!-- HTML -->
<div id="cabecalho">Meu Cabeçalho</div>
/* CSS — selecionado com # */
#cabecalho {
  background-color: navy;
  color: white;
}

Em JavaScript: document.getElementById("cabecalho")

Atributo class

Identifica um grupo de elementos. Pode ser reutilizada quantas vezes for preciso, e um elemento pode ter várias classes separadas por espaço.

<!-- HTML -->
<p class="destaque">Texto importante</p>
<p class="destaque aviso">Importante e de aviso</p>
/* CSS — selecionado com . */
.destaque { font-weight: bold; }
.aviso     { color: red; }

Em JavaScript: document.querySelectorAll(".destaque")

Diferenças

Característica id class
Unicidade Único por página Pode repetir
Seletor CSS #nome .nome
Especificidade Mais alta Mais baixa
Por elemento Apenas um Vários, ao mesmo tempo
Uso típico Header, footer, âncoras Botões, cards, estilos reutilizáveis

Boas práticas

  • Use id para elementos estruturais e únicos da página.
  • Use class para estilos que se repetem — é a escolha padrão para a maioria dos casos.
  • Evite estilizar por id: a especificidade alta dificulta sobrescrever o estilo depois.
  • Nomeie em kebab-case, de forma descritiva: menu-lateral, não div1.
